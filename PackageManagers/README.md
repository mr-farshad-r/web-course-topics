A package manager is a tool that automates the process of installing, upgrading, configuring, and removing third-party libraries (packages) that your project depends on. Every programming ecosystem has at least one -- JavaScript has npm/yarn/pnpm, Python has pip, PHP has Composer, and operating systems have their own (apt, brew, choco).

- Package Managers
  - [Node Package Manager (NPM)](./NPM/README.md) 🔴
  - [Yarn](./Yarn/README.md)
  - PNPM (Performant NPM) -- fast, disk-efficient
  - Advanced Package Tool (APT) -- Debian/Ubuntu Linux
  - Preferred Installer Program (PIP) -- Python
  - Homebrew 🍺 -- macOS
  - Composer -- PHP
  - Chocolatey -- Windows
  - Bower (Deprecated) -- front-end packages, replaced by npm/yarn
