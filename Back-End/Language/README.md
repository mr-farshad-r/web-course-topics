Choosing a back-end programming language is one of the first and most impactful decisions in a project. Each language has its own ecosystem, frameworks, performance characteristics, and community. The good news: core back-end concepts (HTTP, databases, security) are language-agnostic.

- Backend Languages
  - How to choose 🔴
    - Ecosystem and libraries
    - Performance requirements
    - Team familiarity
    - Hosting options
    - Job market
  - Concepts common to all
    - HTTP server / framework
    - Routing
    - Middleware
    - Database driver / ORM
    - Templating
    - Authentication
  - Languages in this course
    - [Node.js (JavaScript)](./Nodejs/README.md) 🔴
      - [Express.js](./Nodejs/Expressjs/README.md)
      - [PM2](./Nodejs/PM2/README.md)
    - [PHP](./PHP/README.md)
      - Laravel, CodeIgniter
    - [Python](./Python/README.md)
      - Flask, FastAPI, Django
  - Other popular options (self-study)
    - Java (Spring Boot)
    - C# (.NET)
    - Go
    - Ruby (Ruby on Rails)
    - Rust
  - Compiled vs Interpreted 🔴
  - Typed vs untyped
