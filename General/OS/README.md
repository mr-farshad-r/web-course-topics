An Operating System (OS) is the software that manages hardware resources and provides services for programs. Every web developer should understand OS fundamentals because their applications run on one -- whether it's a laptop, a production server, a container, or a mobile device. Most servers run Linux, most developers use macOS or Windows, and the differences matter.

- Operating Systems
  - [Linux](./Linux/README.md) 🔴 -- the dominant server and container OS
  - [macOS](./MacOS/README.md) -- the most popular OS for web developers
  - [Windows](./Windows/README.md) -- the most common desktop OS, with WSL
